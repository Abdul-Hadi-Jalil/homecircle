# HomeCircle mobile

Flutter mobile foundation for HomeCircle. Start with the [root README](../README.md) and [setup guide](../docs/setup.md).

Run `flutter pub get`, then `flutter run --dart-define-from-file=config.local.json` after copying and editing `config.example.json`. Without configuration, the app shows a development setup screen. Run `flutter analyze` and `flutter test` for isolated checks.
